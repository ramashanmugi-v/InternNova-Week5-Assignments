# InternNova Week 5 Assignment - Advanced Java

## Objective
To understand advanced Java concepts through practical programming tasks.

## Tasks Completed

### Task 1: Packages
Created a custom studentmanagement package and displayed student information.

### Task 2: Interfaces
Implemented a Payment interface using UPIPayment and CardPayment classes.

### Task 3: Abstract Classes
Created an abstract Shape class and calculated Circle and Rectangle areas.

### Task 4: File Handling
Stored student information in a text file and read the file contents.

### Task 5: Multithreading
Created two threads to print numbers and display messages simultaneously.

## Concepts Used
- Packages
- Interfaces
- Abstract Classes
- File Handling
- Exception Handling
- Multithreading

## Conclusion
This assignment helped me understand Advanced Java concepts through practical implementation.
